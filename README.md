# StudySnap 1.0

เว็บแอปต้นแบบสำหรับจัดการการบ้าน ตารางเรียน และเวลาโฟกัส

## วิธีเปิด
1. แตกไฟล์ ZIP
2. เปิดโฟลเดอร์ `StudySnap_v1` ใน VS Code
3. เปิด `index.html` ในเบราว์เซอร์ หรือใช้ส่วนขยาย Live Server
4. เริ่มเพิ่มการบ้านและตารางเรียนได้เลย

## ฟีเจอร์
- Dashboard และความคืบหน้าการบ้าน
- เพิ่ม/แก้ไข/ลบการบ้าน, ค้นหาและกรองรายการ
- เพิ่ม/แก้ไข/ลบตารางเรียนรายสัปดาห์
- Focus timer 15/25/45/60 นาที
- บันทึกเซสชันโฟกัสและ XP
- สถิติจากข้อมูลที่บันทึกจริง
- ตั้งชื่อและเป้าหมาย
- ส่งออกข้อมูลสำรองเป็น JSON
- Responsive สำหรับมือถือและเดสก์ท็อป

## ข้อจำกัดของต้นแบบ
- ข้อมูลเก็บไว้ในเบราว์เซอร์เครื่องนี้เท่านั้น ไม่ซิงก์ข้ามอุปกรณ์
- ยังไม่มีบัญชีผู้ใช้, push notifications, ระบบชำระเงิน หรือโฆษณา
- ต้องทดสอบเพิ่มเติมก่อนเผยแพร่จริง
- Google Fonts ต้องใช้อินเทอร์เน็ตเพื่อโหลดฟอนต์ Noto Sans Thai; หากออฟไลน์จะใช้ฟอนต์สำรอง

## โครงสร้าง
- `index.html` โครงสร้างหน้าเว็บ
- `css/style.css` การออกแบบและ responsive
- `js/app.js` ระบบงานและการบันทึกข้อมูล
